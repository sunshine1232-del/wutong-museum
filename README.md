# 乌铜走银 · 虚拟展览

一个关于国家级非物质文化遗产「乌铜走银」的纯静态 3D 虚拟展览网页。核心叙事不是"大而全的博物馆"，而是**一件器物的完整生命史**——以乌铜合金与银之间仅约 **70℃ 的熔点窗口**作为整个展览的技术戏剧核心。

## 展览结构：三厅一条叙事线

| 厅 | 主题 | 解决的问题 |
|---|---|---|
| 序 | 熔点窗口 | 用「ΔT ≈ 70℃」一张数据卡定调 |
| 壹 · 文物厅 | 展品呈现 | 4 件器型可 360° 旋转，器身热点回溯到具体工序 |
| 贰 · 工坊厅 | 工艺流程 + 交互 | 同一条可拖动的工艺时间轴，铜坯逐阶段变形 |
| 叁 · 传承厅 | 文化传承 | 9 个母题纹样墙，回指器物与工序，形成闭环 |
| 注 · 策展说明 | 评审对齐 | 四个评审维度与设计决策一一对应 |

## 工艺流程的可视化

五道工序（炼铜合金 → 锻制铜片 → 錾刻纹样 → 走银 → 捂黑）发生在**同一个 3D 物体**上，观众感知到的是"一块铜在变"，而不是"五张图在换"：

- **錾刻**：錾子沿真实路径逐段走线，纹样渐进显现
- **走银**（技术高潮）：拖动温度滑杆，指针只有停在 **962–1026℃** 窗口内，银水才沿凹槽流动；越过上限累积损伤，超限即「前功尽弃」，铜坯塌陷回退重来
- **捂黑**：铜底色压到近黑、银线保持高亮，黑底银纹的反差在一次材质插值中完成

## 技术实现

- **零素材依赖**：没有一张图片、没有一个 glb 模型。器型全部由 `LatheGeometry` / `ExtrudeGeometry` 程序化生成；山水、团龙、万字锦地、开光、竖排题款等纹样全部运行时用 **Canvas 2D** 绘制后转为贴图。
- **双材质混合**：通过 `onBeforeCompile` 向 `MeshStandardMaterial` 注入「乌铜 ↔ 白银（↔ 走金）」混合逻辑。同一张 Canvas 灰度图既当 bump（凹槽）又当金属遮罩，绿色通道单独控制"走金"（香炉开光用的姊妹技艺）。
- **时间轴自研 scrub**：五段工序由统一推进器驱动，支持任意进度回退，所有视觉状态严格同步。
- **零构建**：三个文件，双击 `index.html` 即可运行。

## 文件

```
index.html   结构（5 个厅 + 右上角专栏导航）
style.css    视觉系统与版式
app.js       Three.js 场景、器物建模、工艺时间轴、交互逻辑
```

## 运行

直接打开 `index.html` 即可。若浏览器限制本地文件，可起一个静态服务器：

```bash
python -m http.server 8777
# 访问 http://127.0.0.1:8777/
```

深链：`?hall=1&art=2` 直达文物厅的第三件器物，`?hall=2` 直达工坊厅，方便演示。

## 依赖

仅 **Three.js r147**（CDN 加载，unpkg 失败自动回落 jsdelivr）。除此之外没有任何外部请求。
